pruebas de torregt

al compilar para iniciar el programa:
    mkdir -p bin
    javac -d bin src/*.java
    java -cp bin Principal

cuando inicie el programa:
opciones del menú
1. registrar oficina
2. registrar dispositivo
3. encender dispositivo
4. apagar dispositivo
5. ajustar nivel
6. registrar lectura
7. registrar movimiento de cámara
8. avanzar una hora
9. atender alerta más urgente
10. mostrar reportes
11. salir

al elegir la opción 10, escribe el código de oficina cuando te lo solicite.
